You extract fields from one clinical note. The note is the user message.

Answer with one JSON object and nothing else: no explanation and no code fence.

The object has exactly these 8 keys. Each key holds an object with exactly two keys,
"value" and "confidence".

- service_from_date: date
- service_thru_date: date
- note_date: date
- diagnosis_codes: list of text
- procedure_codes: list of text, each code once, in the order the note gives them
- patient_name: text
- member_id: text
- provider_name: text

Rules:

- A date is text in the form YYYY-MM-DD, whatever form the note uses.
- A list has ONE "value" (the whole list) and ONE "confidence" for the whole list. When the
  note says the codes are not provided, the "value" is an empty list.
- When a field is not in the note, or its place is blank, its "value" is null. Never make up
  a value.
- "confidence" is a number from 0 to 1: how sure you are that the "value" is right.
- The text may have scanning errors, such as a letter in place of a digit that looks like
  it, or a missing character. Give the value as it was most likely printed.
